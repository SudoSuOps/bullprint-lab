The mark is geometry

The rule we set before drawing anything: **no decoration that creates a pressure point.** If branding fights comfort or manufacturability, comfort and manufacturability win.

So the ₿ is not a logo applied to an insert. It is the region of the top surface where no honeycomb pocket is cut. The mark sits at the top plane, flush with the rim, standing proud of the recessed cells around it. Run a fingertip across it and there is no step to find.

Getting there took four attempts. The first three tried to make honeycomb cells conform to the glyph outline, and all three failed the same way: cells that get trimmed too small have to be dropped, the mark bleeds outward into a blob, and the counters inside the B fill in. The version that worked stopped fighting the lattice and evaluates the surface point by point instead, so the mark is exact at any size and the honeycomb around it is never disturbed.
